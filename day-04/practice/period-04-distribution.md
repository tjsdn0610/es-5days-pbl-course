## (공통·필수) 문제 1 — 50,000원 단위 가격 분포

`price`와 Count of records를 사용해 가격대별 Bar를 만드세요. 자동 막대 수를 맞추려고 `Decrease granularity`를 반복하지 말고 `Create custom ranges`를 사용합니다.

권장 구간 예:

- 0 이상 50,000 미만
- 50,000 이상 100,000 미만
- 100,000 이상 150,000 미만
- 150,000 이상 200,000 미만
- 200,000 이상

### 결과 입력

- 실제 입력한 구간: 0–50,000 / 50,000–100,000 / 100,000–150,000 / 150,000–200,000 / 200,000 이상
- 구간 사이 빈틈·중복 확인 방법: 한 구간의 상한이 다음 구간의 하한과 같게 맞추고(50,000·100,000…), Lens custom range는 [하한, 상한)의 반개구간이라 경계값이 한 구간에만 속한다. 각 구간 Count 합(3,621 + 2,289 + 1,359 + 1,264 + 1,467 = 10,000)이 전체 문서 수와 일치하는지로 빈틈·중복이 없음을 확인.
- 가장 많은 가격 구간: 0–50,000
- 해당 구간 실제 문서 수: 3,621
- 제목: `가격 구간별 상품 수`
- 캡처 파일: (가격 구간 Bar 화면 캡처 필요 — p04-p04-q01-price-range.png)

## (공통·필수) 문제 2 — 재고 상태 Donut과 기준값 검증

차트 유형 `Pie`에서 `in_stock` Top values와 Count of records를 설정한 뒤, `Style → Appearance → Donut hole → Medium`으로 Donut을 만드세요. 차트 목록에서 Donut을 찾지 않습니다.

### 결과 입력

- true 실제 값: 8,469
- false 실제 값: 1,531
- 합계: 10,000
- 전체 20,000과 일치하는가: 문제지 기준 20,000과는 불일치. 현재 환경 전체 문서 수 10,000과는 정확히 일치(8,469 + 1,531 = 10,000).
- 비율 또는 값 표시 방식: true 84.69% / false 15.31% (Donut 조각에 percent 표시)
- 제목: `재고 상태 비율`
- 한 조각만 보일 때 먼저 확인할 조건: ① KQL·filter pill에 `in_stock` 조건이 걸렸는지 ② Top values의 Number of values가 1인지 ③ 시간 범위가 좁아 한쪽 값만 남았는지
- 캡처 파일: (재고 Donut 화면 캡처 필요 — p04-p04-q02-stock-donut.png)

## (공통·필수) 문제 3 — 월별 상품 등록 Line과 잘못된 해석 수정

`created_at` Date histogram과 Count of records를 사용하고 `Minimum interval`에 `1M`을 입력해 월 단위 Line을 만드세요.

다음 문장을 데이터에 맞게 수정하세요.

> 월별 판매량이 증가하거나 감소하는 모습을 보여 준다.

### 결과 입력

- 선택한 interval: `1M` (월 단위)
- 보이는 월 구간: 2025-08 ~ 2026-08 (13개 버킷). 양 끝은 부분 월 — 데이터 실제 범위가 2025-08-27 ~ 2026-08-26.
- 실제 패널 제목: `월별 상품 등록 분포`
- 수정한 설명 문장: "월별 **상품 등록 건수**의 변화를 보여 준다. 완전한 달(2025-09 ~ 2026-07)은 약 745~872건으로 큰 추세 없이 평탄하고, 양 끝 달(2025-08: 131건, 2026-08: 745건)은 데이터 기간이 잘려 낮게 보인다."
- `created_at`의 실제 의미: 상품이 카탈로그에 **등록된** 시각. 판매·주문 시점이 아니다.
- 판매 추이를 알려면 추가로 필요한 사건/field: 주문/판매 이벤트 문서 (`order_date`, `quantity`, `amount` 등). 상품 문서 하나가 아니라 주문 1건 = 문서 1건 구조가 필요하다.
- 캡처 파일: (월별 Line 화면 캡처 필요 — p04-p04-q03-monthly-line.png)

## (개인·필수) 문제 4 — 분포·비율·시간 중 하나 선택

자기 질문에 필요한 유형 하나만 선택해 설계하거나 만드세요.

| 선택 | 필요한 데이터 | 적합한 질문 예 |
|---|---|---|
| 분포 | 숫자 field | 값이 어느 구간에 몰려 있는가? |
| 비율 | 상태·범주 field | 상태별 구성은 어떠한가? |
| 시간 | 날짜 field | 기간별 문서 수는 어떻게 달라지는가? |

- 선택 유형: 분포
- 사용자 질문: 선수들의 시즌 타율(AVG)은 어느 구간에 몰려 있는가?
- field와 mapping type: `AVG` / float
- 그룹/구간/시간 단위: custom range — <0.25 / 0.25–0.28 / 0.28–0.31 / 0.31–0.34 / 0.34 이상
- 차트: Bar (가격 구간 분포와 동일 방식)
- 완료 기준: 5개 구간이 표시되고 Count 합이 5,000
- 실제 결과 또는 부족한 데이터: <0.25 → 1,683 / 0.25–0.28 → 751 / 0.28–0.31 → 766 / 0.31–0.34 → 755 / 0.34+ → 1,045. 중간대(0.25~0.34)가 고르고 양 극단(특히 0.25 미만)이 두꺼운 분포. 전체 평균 0.281, 범위 0.18~0.38.
- 해석 시 주의할 한계: `AVG`는 시즌 누적 타율이라 타석/경기 수와 함께 봐야 한다. 소수 타석 선수의 극단적 타율(0.18, 0.38 등)이 양 끝 구간을 부풀렸을 수 있다.

## (선택 도전) 문제 5 — 가격 구간 대안 비교

50,000원 구간과 자신이 설계한 다른 구간을 비교하세요. field와 Count는 유지합니다.

대안 구간: 100,000원 단위 (0–100k / 100k–200k / 200k–300k / 300k 이상)

| 비교 | 50,000원 단위 | 대안 구간(10만 원 단위) |
|---|---|---|
| 막대 수 | 5 | 4 |
| 읽기 쉬움 | 구간이 촘촘해 저가대(5만 미만 3,621건)가 따로 보임 | 단순하지만 0–100k에 5,910건이 뭉쳐 저가대 세부가 사라짐 |
| 판단에 유용함 | 상품이 저가에 밀집한 사실을 드러냄 | 큰 그림만, "대부분 10만 원 미만" 정도만 확인 |

- 최종 선택과 이유: 50,000원 단위. `price` 최빈 구간이 5만 원 미만(3,621건)이라 저가대를 더 잘게 나눠야 상품 구성이 드러난다. 10만 원 단위는 저가대 정보를 뭉개 버린다.
